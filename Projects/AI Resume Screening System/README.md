# 📄 AI Resume Screening System

## 📖 Overview

The AI Resume Screening System is an intelligent recruitment automation workflow built with **n8n** and **OpenAI**.

It automatically analyzes candidate resumes, extracts key information, evaluates qualifications, scores applicants based on predefined criteria, stores candidate records, and generates AI-powered hiring recommendations for recruiters.

---

## 🚀 Features

- AI Resume Analysis
- Candidate Skill Extraction
- Experience Evaluation
- Education Verification
- Resume Scoring
- Candidate Ranking
- Google Sheets Integration
- Google Drive Report Generation
- Automated HR Email Notifications

---

## ⚙️ Workflow

```text
Resume Submission
        │
        ▼
Webhook
        │
        ▼
OpenAI Resume Analysis
        │
        ▼
Extract:
• Candidate Name
• Skills
• Experience
• Education
• Resume Score
• Hiring Recommendation
        │
        ▼
Store Candidate Record
(Google Sheets)
        │
        ▼
Generate Evaluation Report
(Google Drive)
        │
        ▼
Send HR Notification
```
