# 📄 AI Contract & Document Analyzer

## 📖 Overview

The AI Contract & Document Analyzer is an intelligent automation workflow built with **n8n** and **OpenAI**.

It automatically receives contracts and business documents, extracts key information using AI, analyzes legal and business clauses, generates a structured summary, stores the results, and produces a professional report for review.

---

## 🚀 Features

- AI Contract Analysis
- Intelligent Document Summarization
- Key Clause Extraction
- Risk & Obligation Detection
- OpenAI Integration
- Google Drive Storage
- Automated Report Generation
- Business Document Processing

---

## ⚙️ Workflow

```text
Document Upload
      │
      ▼
Google Drive Trigger
      │
      ▼
Extract Document Text
      │
      ▼
OpenAI Document Analysis
      │
      ▼
Generate Structured Summary
      │
      ▼
Save Results
      │
      ▼
Email / Final Report
```
