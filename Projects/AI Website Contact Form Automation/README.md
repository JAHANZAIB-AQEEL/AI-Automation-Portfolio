# 🌐 AI Website Contact Form Automation

## 📖 Overview

The AI Website Contact Form Automation is an intelligent customer inquiry management workflow built with **n8n** and **OpenAI**.

It automatically processes website contact form submissions, analyzes customer inquiries using AI, categorizes requests, determines priority, stores customer information in a CRM database, generates inquiry summaries, and sends personalized confirmation emails.

---

## 🚀 Features

- AI Contact Form Analysis
- Automatic Inquiry Categorization
- Priority Classification
- Customer Intent Detection
- Google Sheets CRM Integration
- Google Drive Inquiry Reports
- Personalized Email Responses
- End-to-End Contact Form Automation

---

## ⚙️ Workflow

```text
Website Contact Form
          │
          ▼
Webhook
          │
          ▼
AI Inquiry Analysis
          │
          ▼
Determine:
• Inquiry Category
• Priority
• Customer Intent
• AI Summary
          │
          ▼
Store Customer Record
(Google Sheets CRM)
          │
          ▼
Generate Inquiry Report
(Google Drive)
          │
          ▼
Send Confirmation Email
```
