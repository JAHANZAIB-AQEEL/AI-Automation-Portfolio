# 🏢 Enterprise AI Operations Dashboard

## 📖 Overview

The Enterprise AI Operations Dashboard is a multi-agent AI automation workflow built with **n8n** and **OpenAI**.

It analyzes monthly business data using specialized AI agents for Sales, Marketing, Finance, and Customer Support. Their outputs are merged into a single executive report, which is automatically archived and emailed to company leadership.

---

## 🚀 Features

- Multi-Agent AI Architecture
- Business Coordinator AI
- Sales AI Analysis
- Marketing AI Analysis
- Finance AI Analysis
- Customer Support AI Analysis
- Executive AI Summary
- Google Sheets Integration
- Google Drive Report Generation
- AI Executive Email
- Automated Workflow using Webhooks
