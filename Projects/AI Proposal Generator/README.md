# 📑 AI Proposal Generator

## 📖 Overview

The AI Proposal Generator is an intelligent business automation workflow built with **n8n** and **OpenAI**.

It automates the proposal creation process by analyzing client requirements, generating professional business proposals, organizing project details, storing proposal records, creating proposal documents, and delivering completed proposals via email.

---

## 🚀 Features

- AI Proposal Generation
- Client Requirement Analysis
- Project Scope Generation
- Timeline & Deliverables Creation
- Pricing Summary Generation
- Google Sheets Integration
- Google Drive Proposal Storage
- Automated Email Delivery

---

## ⚙️ Workflow

```text
Client Request
       │
       ▼
Webhook
       │
       ▼
OpenAI Proposal Generator
       │
       ▼
Generate:
• Executive Summary
• Project Scope
• Deliverables
• Timeline
• Pricing Summary
       │
       ▼
Store Proposal Record
(Google Sheets)
       │
       ▼
Generate Proposal Document
(Google Drive)
       │
       ▼
Send Proposal Email
```
