# 📄 AI Resume & Cover Letter Generator

## 📖 Overview

The AI Resume & Cover Letter Generator is an intelligent career automation workflow built with **n8n** and **OpenAI**.

It automatically generates professional resumes and personalized cover letters based on user information, work experience, education, and job descriptions. The workflow organizes applicant data, creates ATS-friendly documents, stores generated files, and delivers them via email.

---

## 🚀 Features

- AI Resume Generation
- AI Cover Letter Creation
- ATS-Friendly Resume Formatting
- Personalized Job Application Documents
- Google Sheets Integration
- Google Drive Document Storage
- Automated Email Delivery
- End-to-End Resume Automation

---

## ⚙️ Workflow

```text
Candidate Information
         │
         ▼
Webhook
         │
         ▼
AI Resume Generator
         │
         ▼
Generate:
• Professional Resume
• Personalized Cover Letter
• Career Summary
• Skills Section
• Experience Highlights
         │
         ▼
Store Candidate Record
(Google Sheets)
         │
         ▼
Save Documents
(Google Drive)
         │
         ▼
Email Resume & Cover Letter
```
