# 📱 AI Social Media Content Generator

## 📖 Overview

The AI Social Media Content Generator is an automation workflow built with **n8n** and **OpenAI** that generates engaging social media content for businesses. It creates platform-specific posts, organizes content, stores results, and delivers them automatically.

---

## 🚀 Features

- AI Content Generation
- Multi-Platform Post Creation
- Marketing Copy Generation
- Hashtag Recommendations
- Content Organization
- Google Sheets Integration
- Google Drive Storage
- Automated Email Delivery

---

## ⚙️ Workflow

```text
User Request
      │
      ▼
Webhook
      │
      ▼
OpenAI Content Generator
      │
      ▼
Generate Captions & Hashtags
      │
      ▼
Save Content
      │
      ├── Google Sheets
      ├── Google Drive
      └── Email Delivery
```
